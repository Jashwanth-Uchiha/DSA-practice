# DSA Practice

A topic-wise collection of Data Structures and Algorithms problems solved in C++.

## Topics

| Topic | What you'll find |
|---|---|
| [Arrays](./ARRAYS/) | Array basics, two pointers, prefix sums, subarrays, sorting and matrix problems |
| [Binary Search](./Binary%20Search/) | Binary search patterns, rotated arrays, answer-space search and matrix search |
| [Binary Trees](./Binary%20Trees/) | Tree height, traversals, diameter, balanced trees, sum tree and boundary traversal |
| [Graphs & Grids](./Graphs%20%26%20Grids/) | Grid and graph-style problems |
| [Recursion](./Recursion/) | Recursion, backtracking, subsets, permutations and combination problems |
| [Stacks](./Stacks/) | Stack implementation, stack recursion, monotonic stack patterns and asteroid collision |
| [Keywords](./keywords/) | C++ language notes and small examples |
| [Utilities](./Utilities/) | Small helper or testing files |

## File naming

- `lc_123.cpp` — a LeetCode solution identified by problem number.
- `gfg_problem-name.cpp` — a GeeksforGeeks solution.
- Other files retain their existing names while the repository is being organized.

## Suggested format for new solutions

For each new problem, try to include:
1. Problem name and platform/problem link.
2. Approach in a few lines.
3. Time and space complexity.
4. C++ solution.

This repository is a learning log. Solutions may be revised as better approaches are learned.
